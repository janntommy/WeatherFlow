🌦️ Weather Data Pipeline — PySpark ETL

A climate data pipeline built with PySpark, processing historical weather data from NOAA (GHCN-Daily) weather stations using a layered architecture (Bronze → Silver → Gold), with a final load into PostgreSQL and visualization of climate trends.

📌 Project Goal

This project simulates a real-world data engineering workflow: from ingesting raw, "messy" data, through cleaning and transformation, to delivering clean, aggregated data ready for analysts and dashboards.
